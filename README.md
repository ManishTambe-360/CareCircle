# CareCircle AI

AI-powered elderly activity monitoring and anomaly detection system.

## 🚀 Live Demo

**Frontend:** https://care-circle-ai-279j.onrender.com

**Backend API:** https://carecircle-ep9p.onrender.com

## 🧠 Project

CareCircle AI uses machine learning to analyze activity patterns, detect unusual behavior, and provide actionable insights for caregivers.

### 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- FastAPI
- Python
- Scikit-learn
- Isolation Forest
- CASAS Smart Home Dataset
- Render
